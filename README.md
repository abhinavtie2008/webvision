The website which we are working on is : **SAARTHI PARIVAHAN**, A Government transportation facilitating website 

## About the Project

This project is our attempt to make the **Sarathi Parivahan website** easier to use, especially on mobile devices.

Government websites provide important services, but users can sometimes struggle to find the right option or understand where to start. We wanted to work on these usability issues and build a cleaner, more organised interface for driving licence-related services. Also the UI seems a bit outdated, and less functional for the user.

As upcoming adults, we student will use this site to apply for our driving licence but the site lacks the navigating and ease of use for the user. many features like contact help, that should be on the Home Page are not there. Also an addition of chatbot makes it easy for the user to go through the process as it guides the user through the process. Along with this we are trying to add some other features the will make the overall experience better for the user
## Features

- **Clean Interface:** A simple layout that makes the available services easier to find.
- **State Selection:** Users can select a state to begin exploring driving licence services.
- **Driving Licence Services:** The homepage displays eight service cards to help users identify the service they need.
- **Mobile-Friendly Design:** The layout is designed to work on mobile phones, tablets, and desktops.
- **Easy Navigation:** Important options are organised to reduce confusion and make the website easier to explore.
